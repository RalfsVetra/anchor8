# stm8-bootloader

It is yet another bootloader for the STM8 platform that implements IAP principles. Although it probably falls
into the "toy" bootloader category, it can still serve as a solid reference point for education. This project
emphasizes simplicity and modularity over optimizing for size and efficiency. It is written to be easy to
understand and learn from. That's why it will probably stay in the "toy" category forever.
